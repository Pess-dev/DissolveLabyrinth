You appear in an unusual place. The surroundings seem strange. The first thing you realise is that you can distort reality and interact with the world as if dissolving it. But after travelling a sufficient distance it becomes clear that the world itself is distorted....

Finding the keys, activate the paintings and progress further through purgatory...

Controls:

Walking and Turning: W A S D + Mouse

Ability: Spacebar
